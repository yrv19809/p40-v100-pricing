## 雨云显卡云和普通云服务器的区别

普通云服务器有 CPU、内存、硬盘，就是没显卡。显卡云在同样规格的机器上多挂了一块 GPU，并且以 vGPU 的形式分配显存——也就是说一张物理 P40 会被切成多份给不同用户，你拿到的显存就是套餐里写的那几个 G。

雨云在这类机器上做了几件省事的事：

- 系统里默认装好 NVIDIA 显卡驱动，CUDA 也已启用。宿迁、宁波的 P40 机型上，`nvidia-smi` 显示的是 Driver 535.129.03、CUDA 12.2，不用自己折腾驱动。
- RDP 做过 GPU 相关优化：NVIDIA 的 OpenGL over RDP 支持已打开，H.264/AVC 硬件编码也开着，远程桌面帧率上限从默认 30FPS 提到了 60FPS。所以用 Windows 远程桌面连过去跑 OpenGL 程序、看视频，能真的吃到显卡。
- 支持 SillyTavern、AstrBot 这类大模型前端一键部署，也有 1Panel、MCSManager、Cloudreve、Docker 和 Java 环境。想快速起个 AI 绘画站或者游戏服务端，不用从裸系统开始配。

操作系统可选 Ubuntu 22.04 Server LTS 和 Windows 2022 数据中心版（GPU 版），装完切系统也可以。

## 固定计费和"日常网吧型"该选哪个

这是雨云显卡云里最值得算清楚的一笔账。

**固定计费**就是传统包月：不管开不开机，每月照付。广州 RTX3080 长租型 978 元 / 月，深圳 V100 算力长租型 638 元起 / 月。适合要长期挂着跑的服务——稳定的 AI 绘画站、常年在线的渲染节点、游戏挂机。

**日常网吧型**是把月费和时长拆开：交一笔很低的固定费（广州 29 元、深圳 28 元），每天开机用多少小时按 2.5 元 / 小时计，关机不计费，开通时还会送 5 小时。深圳这一条线的加时价格是 1 小时 2.5 元、5 小时 12 元、24 小时 50 元。

算一下就知道分界线在哪：深圳按 2.5 元 / 小时、一个月用满 30 天来算，只有每月实际开机不到 250 小时左右，网吧型才比 638 元的长租型更划算。反过来说，一周只玩两三个晚上云游戏，或者偶尔跑一次渲染，网吧型明显更省——前提是你接受 IP 随开机动态生成、每次开机环境可能变化的体验。

## 显存怎么挑：别只看核数

雨云 P40 的六档里，真正决定"能不能跑"的是显存，CPU 核数更多影响的是并发和编译速度。

- **1GB 显存**（入门版 / 标配版，40~59 元起）：够跑轻量挂机、OpenGL 图形程序、简单的命令行推理。想跑 Stable Diffusion 出图会很紧，模型权重加载就可能顶到上限。
- **2GB 显存**（小型工作，68~88 元起）：能跑通小尺寸的 AI 推理和轻度 3D 预览，出图分辨率要压得比较低。
- **4GB 显存**（小型工作+、高配，135~168 元起）：这一档是很多教程推荐的起点，因为不少 AI 模型对显存的最低要求就在这个量级。用 4G 显存跑 SD 出 512×512 图是可行的。
- **8GB 显存**（旗舰，258~268 元起）：P40 显存切分里最大的一档，适合显存要求更高的推理任务和 3D 渲染。

需要说实话的地方在于：Tesla P40 是 Pascal 架构的老卡，没有 Tensor Core，FP16 算力被压到 1:64 的比例（约 183.7 GFLOPS），FP32 是 11.76 TFLOPS。跑 AI 绘画和大模型推理，它的实际速度比不上同显存的 RTX 系列。所以 P40 系列的定位很明确——**便宜、按需、够跑通流程**，不适合拿来做正经的模型训练。真要长期跑重负载，往上看 RTX3080 或 V100 那两条线。

## 网络、IP 和几个容易踩的限制

这部分不写在购买页显眼位置，但会直接影响能不能用：

- **NAT 还是独立公网 IP**。宿迁的部分机型默认是 NAT 模式，共用公网 IP，可以设置 10 条端口转发。NAT 模式没法直接开放 80、443 端口对外提供网站访问，做游戏私服、内网穿透、远程桌面没问题，建站不合适。
- **独立公网 IP 要加钱**。宁波加购是 30 元 / 个 / 月，可选 100G 宁波电信普防、20G 宁波移动普防、100G 宁波联通普防等；宿迁的独享公网 IP 带 150G 防御，成本本身不低，有人反馈独享 IP 的价格几乎和服务器本体相当。广州节点加购 150G 阿里智能月防 IP 或 100G 腾讯智能月防 IP 是 75 元 / 月，基础价格里已含 1 个 IP。
- **硬盘可以弹性加**。高速固态 0.4 元 / G / 月，机械盘 0.1 元 / G / 月，默认盘通常只有 60GB 左右。想跑 SD，装模型、装依赖、放输出图，实际用起来扩容到 150GB 以上比较稳。深圳那一条线最高可以扩到 1000G 以上。
- **大陆节点的域名要备案**。境内机器上用域名做 HTTP 业务，得先完成域名备案并过白，否则访问不了。纯自用、不开网站的用途不受这个限制。
- **流量**。P40 系列和广州、深圳的显卡云基本是不限流量，宁波另有流量计费的大带宽模式，走这条路要盯紧流量费用。

## 下单流程

1. 注册账号，绑定微信领券。这一步别跳过，券是绑微信后发的。
2. 进控制台，在"云产品"或总览里找到显卡云 / 云服务器入口。
3. 选地域，再选显卡型号（P40 / RTX3080 / V100），然后挑档位。
4. 计费方式选固定月付还是日常网吧型，硬盘按需要扩容。
5. 系统选 Windows 2022（GPU 版）还是 Ubuntu 22.04，按用途定。
6. 购买后用远程桌面（Windows）或 SSH 连进去。纯挂机、跑脚本、做端口转发可以先用 NAT 模式；要建站或需要固定入口，加购独立公网 IP。

雨云成立于 2018 年，持有工信部颁发的 ISP、IDC、CDN 相关许可，云服务器和游戏云产品支持低价试用，退款政策是 7 天无理由、每账号限 3 次。这些条款在买之前值得自己复核一遍，因为它直接决定试错成本。

## 一句话结论

预算卡在几十块、想跑通 AI 绘画或者挂机，宁波 P40 的 2GB 或 4GB 显存档是性价比最合理的入口；需要稳定长期跑，深圳 V100 长租型 638 元 / 月比广州 RTX3080 便宜三分之一左右；只是偶尔用几个小时，任何一条线的"日常网吧型"都更划算。拿不准就用一天的试用价先测，显存够不够，第一次开机就知道了。
